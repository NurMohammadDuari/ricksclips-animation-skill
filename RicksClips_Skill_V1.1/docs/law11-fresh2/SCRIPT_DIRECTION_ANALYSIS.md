## Script problems identified and how direction resolves them (no text was changed)

1. **Repeated information:** "ভাগ্নে" is spoken in sentences 1, 2, 10, 11. Direction answers it with the film's own rhyme: the till he lost (1–2) → the packet at the same door (10) → the nephew he begs for (11). Each repetition gets a DIFFERENT picture; the plan gate "same framing on the same subject in a row" = 2 (target ≤ 3).
2. **Time jumps without context:** the narration jumps ৩ মাস → ১ বছর আগে → ১০ বছর → ১ মাস → ৩ মাসে → ৬ মাস. Direction: cuts land ONLY on these named jumps (11 takes, 10 cuts = 0.83/10 s, gate ≤ 0.9); the door motif repeats night → morning → night so the audience re-orientates by place, not by text; the ১০ বছর পর drop carries a cold light.
3. **Emotional progression:** pride → plea → dread → warmth → warning → montage → grief → injustice → vindication → defeat → begging → calm → triumph → lesson → address. Each beat gets a mood wash (`moods`, 32 entries ≈ 15.9/min, gate ≥ 12) and a face change; the montage sentence carries its own light turns (gold → spot → cold).
4. **Weak-opening risk:** sentence 1 puts the insult (bhagne ALREADY at the till) on screen inside 2.7 s; first face at 0.0 s (gate ≤ 1.5).
5. **Ending strength:** the lesson (14) is staged at rafi's OWN counter with the red khata still in the desk — the visual proof of the moral — then the outro addresses the camera (15).
